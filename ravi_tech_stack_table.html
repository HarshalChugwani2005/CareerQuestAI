RAVi complete tech stack table organized by layer, tool, and purpose

Layer Technology Purpose Why this choice
DATA INGESTION
Data ingestion JavaScript (MV3) Browser extension tracking job applications on LinkedIn / Indeed Chrome MV3 is the current standard; lightweight, no library needed
Data ingestion LTI Protocol LMS integration with Canvas and Moodle for engagement signals Universal standard — works across all major LMS platforms
Data ingestion Lightcast API Real-time labor market data — 34K+ skills mapped to job demand Best-in-class workforce data; 6-hour refresh cycle
Data ingestion LinkedIn / Indeed APIs Track job activity, interview progress, skill acquisition Direct source of truth for job search behavior
BACKEND & DATA PIPELINE
Backend FastAPI (Python) Core REST API server — all endpoints for models, scores, alerts Async, fast, native Python — perfect fit for ML stack
Backend Apache Kafka Real-time event streaming from browser extension and job portals Handles high-velocity telemetry; enables model retraining replay
Backend PostgreSQL Primary database — student profiles, loan data, risk scores Reliable, relational, strong support for JSON fields
Backend Redis Cache layer for real-time risk scores served to lender dashboard Sub-millisecond reads for live score updates
Backend AWS / GCP Cloud hosting, storage, managed ML deployment GCP Vertex AI integrates natively with model serving pipeline
Backend Docker + Kubernetes Containerisation and orchestration of all services Scalable, reproducible deployments across environments
ML / AI CORE
ML core XGBoost Salary estimation and placement probability prediction Best-in-class for tabular data; handles missing values well
ML core Pycox / DeepSurv Time-to-employment survival curves (the core innovation) Purpose-built for "time until event" — no other tool does this
ML core PyTorch Training DeepSurv neural networks Flexible, industry-standard, large community
ML core scikit-learn Feature engineering, preprocessing pipelines, baseline models Reliable, mature, integrates with XGBoost seamlessly
ML core SHAP Explainability — reason codes for every XGBoost risk rating Gold standard for tree model explanations; satisfies EU AI Act
ML core LIME Local explanations for deep model outputs (student-facing) Model-agnostic; simpler outputs for non-technical users
ML core MLflow Experiment tracking, model versioning, audit trail Required for CECL compliance; tracks every model change
ML core Pandas / NumPy Data wrangling, feature computation, batch processing Standard Python data stack — no alternative needed
ACTIVE CAREER SERVICING
Servicing Claude / OpenAI API Mock interview simulator and resume optimizer (LLM-powered) No fine-tuning needed at MVP stage; prompt engineering suffices
Servicing Python (rule engine) IRR (Interest Rate Reward) engine — milestone → rate reduction logic Rule-based first; add ML layer after data accumulates
Servicing Celery + Redis Async task queue for proactive alerts and early warning triggers Runs background jobs (alert sends, score refreshes) reliably
FRONTEND & DASHBOARDS
Frontend React + TypeScript Student portal and lender enterprise dashboard (two separate apps) Component reuse, strong typing, large ecosystem
Frontend Tailwind CSS Styling for all UI components Fast to build, consistent, no CSS conflicts
Frontend Recharts / D3.js Survival curves, employability score gauges, portfolio charts Recharts for standard charts; D3 for custom survival curve viz
Frontend Vite Frontend build tooling Fastest React dev server; instant HMR
COMPLIANCE & SECURITY
Compliance OAuth 2.0 / JWT Authentication and authorisation for all user types Industry standard; needed for lender-grade security
Compliance AES-256 encryption Encrypting student PII at rest and in transit Required for GDPR / DPDPA compliance
Compliance MLflow audit logs Full audit trail for every model decision and risk rating change Mandatory for EU AI Act and FASB CECL standards
